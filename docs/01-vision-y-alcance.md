# Cliente
Costa Viva es un negocio de Manabí, Ecuador, que vende café,
chocolate artesanal, artesanías de paja toquilla 
elaborados localmente.

# Objetivos del proyecto
1. Tienda en línea funcional, desplegada y accesible con un enlace público.
2. Control de inventario confiable: nunca se vende más de lo que existe.
3. Pagos con tarjeta en modo de prueba (Stripe).
4. Panel para que el dueño gestione productos y pedidos.
5. Repositorio profesional que sirva como portafolio.


# Fuera del alcance 
Aplicación móvil, -multi-idioma, -multi-moneda, -microservicios, -chat en vivo,
recomendaciones con IA, cálculo real de envíos con transportistas, pagos con dinero
real
