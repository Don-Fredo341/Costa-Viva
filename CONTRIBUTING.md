# Guía de contribución

## Commits
- Idioma: inglés.
- Formato: Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`).
- Un commit, un propósito.

## Ramas
- `main` siempre estable.
- Una rama por funcionalidad: `feature/cart`, `fix/stock-bug`.
- Todo cambio entra por Pull Request, con descripción y checklist.
